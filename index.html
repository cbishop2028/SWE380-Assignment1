Project

C++ · Spring 2025 · Team Leader

Digital Logic Simulator

Led a team in designing and implementing a command-line digital logic simulator in C++. The program parses circuit and vector files, schedules events with a priority queue, models gate propagation delays, and prints wire traces over simulated time.

The implementation uses object-oriented classes for gates, wires, and events. It supports AND, OR, NOT, NAND, NOR, XOR, and XNOR gates and includes multiple circuit inputs for testing.
